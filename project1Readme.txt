Project 1 - Data Cleaning & Preparation

Overview
This project focuses on cleaning and preparing a raw ecommerce dataset for analysis using Python and Pandas. The main objective was to improve data quality by handling missing values, validating formats, and removing inconsistencies.

Tools & Technologies
- Python
- Pandas
- Excel

Tasks Performed
- Loaded dataset using Pandas
- Identified missing/null values
- Calculated percentage of missing values
- Handled missing values in CouponCode
- Checked and removed duplicate rows
- Validated unique OrderID
- Standardized date formats
- Verified numeric data types
- Cleaned text columns

Key Learnings
- Data preprocessing workflow
- Handling missing data
- Data validation techniques
- Importance of clean datasets before analysis

Files Included
- project1.py
- Dataset for Data dataset1.xlsx
- Cleaned_dataset.xlsx

## Key Findings
- The dataset contained 309 missing values in the CouponCode column.
- No duplicate rows or duplicate OrderID values were found.
- Date formats were standardized into a consistent format.
- Numeric columns were validated successfully.
- The final dataset was cleaned and prepared for further analysis.

Outcome
Successfully transformed the raw dataset into a clean and analysis-ready dataset for further analytics and SQL operations.
